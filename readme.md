# Mock TianQin Standard Siren Ctalogs

This repo contains two mock TianQin standard siren (TQSS) catalogs.

- LCDM_MBHB is generated based on the standard LCDM model.
- wbin_MBHB is generated based on the wbin model, where the dark energy equation of state parameter, w(z), is reconstruted by redshift binning method.

Multiple configurations for the GW detectors are considered,

- 1TQ: the default case where three satellites form a constellation and operate in a “3 month on + 3 month off” mode;
- 2TQ: a twin constellation of satellites is used that have perpendicular orbital planes to avoid the 3-month gaps in data;
- LISA: the Laser Interferometer Space Antenna mission;
- 1TQ+LISA: a network of TianQin and LISA, with the 1TQ configuration considered;
- 2TQ+LISA: a network of TianQin and LISA, with the 2TQ configuration considered;

For more details of the configurations, see [arXiv:2104.11956](https://arxiv.org/abs/2104.11956).
